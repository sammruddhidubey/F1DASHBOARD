METHODOLOGY & DATA INTEGRITY

Descriptive Boundaries & Scrutineering Rigor

This project represents a descriptive analysis of the course-provided workbook F1 Racing Project Dataset.xlsx (sheet: race_results). It presents observed associations within historical records; it does not claim causal inference or predictive determinism regarding weather or tyre impact.

All historical point totals are preserved as recorded, without retroactive scaling. Missing finish positions for non-finishers are explicitly retained without synthetic zero-imputation.

READ PROJECT REPORT (MD)
TECHNICAL SCRUTINEERING PROTOCOL VERIFIED
01
Zero-Substitution Protocol: Non-finish observations maintain genuine blank finish values rather than distorted artificial positions.
02
Scoring System Authenticity: Points reflect the native scoring system under which each championship grand prix was conducted.
03
Statistically Pure Aggregations: Means are used strictly for finish rankings and grid deltas; sums are reserved for championship points.
